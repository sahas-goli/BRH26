# SpaceX: Make it Legendary (sponsor)

Sponsor link on the site points to x.ai/api (xAI/Grok API).

## Challenge
Space offers huge public datasets, decades of missions, and literature no human can read. Real space data in, a legendary project out.

## Requirements
1. **Built with Cursor** (more Cursor use = more likely to win).
2. **Use the Grok Imagine API or Grok Voice API.**
- Bonus: Grok Bot for project planning and collaboration.
- Spoken at the ceremony: a space theme is **not** required ("would love if it was"); the written brief asks for space data. Submit the project to SpaceX.

## Context
- Cursor was acquired by SpaceX AI; the team also ships Grok Bot, Grok Build, Grok Imagine, Grok Voice.
- xAI API: https://x.ai/api . No credits or promo code published.

## Verified 2026-10-03 (proposal research)

**Facts:** Both APIs are public and documented at docs.x.ai. GROK VOICE: (1) a speech-to-speech voice agent over WebSocket at wss://api.x.ai/v1/realtime?model=grok-voice-latest. grok-voice-latest currently points to grok-voice-think-fast-2.0, which reasons by default. It has server VAD and parallel tool calling: custom client functions with JSON schemas, web_search, x_search, file_search (collections) and remote MCP. Audio is PCM 8-48kHz (24k recommended), Opus, or G.711 mu-law/A-law. Docs give Python and JS examples. It works with OpenAI Realtime SDKs: change the base URL and key (event names differ slightly). Browsers and phones should use ephemeral tokens (prefix xai-client-secret.). It speaks 20+ languages and supports custom voice cloning (up to 120 s of reference audio). Session history is cached for 30 minutes and can be resumed with conversation_id. (2) TTS at POST https://api.x.ai/v1/tts, with inline speech tags (laugh, whisper, pause). (3) STT at https://api.x.ai/v1/stt (grok-voice-transcribe-2.0): 25 languages, word timestamps, diarization, streaming over WebSocket. Official pricing: speech-to-speech $0.08/min ($4.80/hr) plus $0.004 per text input; TTS $15 per 1M characters; STT $0.10/hr REST or $0.20/hr streaming. GROK IMAGINE IMAGE: POST https://api.x.ai/v1/images/generations with grok-imagine-image ($0.02), grok-imagine-image-2.0 ($0.04) or grok-imagine-image-quality ($0.05) per image. n is 1-10, size 1k or 2k, 13 aspect ratios, returns a temporary URL or b64_json, and editing is supported. Docs show the OpenAI SDK working. GROK IMAGINE VIDEO: POST https://api.x.ai/v1/videos/generations returns a request_id; poll GET /v1/videos/{request_id}. Takes text, image or video input (text-to-video, image-to-video, editing). Clips are 1-15 s at 480p (default), 720p or 1080p. Audio is generated by default (generate_audio=False turns it off). Per second: grok-imagine-video $0.05, video-1.5 $0.08, video-1.5-lite $0.02. Rate limit 10 RPS. Rate-limit tiers start at Tier 0 ($0 spent). Auto top-up has a $5 minimum. CURSOR: the free Hobby plan has limited Agent requests. Individual is $20/mo ('generous limits for Grok', Grok Bot access); Teams is $40/user/mo. The cursor.com/students page no longer offers a free Pro year, only 'promotions at events'. Cursor Agent adds a 'Co-authored-by: Cursor' trailer to its commits by default (Settings > Agents > Attribution). Shared transcript links (cursor.com/s/...) with full history and tool calls exist on Teams/Enterprise only. Export Transcript is on every plan but exports text only.

**Gotchas:** Free credits are UNVERIFIED. Current docs.x.ai billing, FAQ and rate-limit pages say nothing about signup credits. Third-party blogs claim $25 at signup plus $150/mo for opting into data sharing (after $5 spent). Budget a $10-20 prepay or ask the SpaceX table. Video is asynchronous and the docs say it 'typically takes up to several minutes', so pre-generate clips or use images for anything live. Voice-agent cost: a 2-minute pitch is about $0.16, so it's cheap. Never ship the raw API key to a browser; mint ephemeral tokens from a server. Two sources disagree on speech-to-speech price ($0.05 vs $0.08/min); the official pricing page says $0.08. The x.ai/api/voice marketing page returned 403, so I have no official latency figure beyond 'sub-second'. To show Cursor use: keep the default Co-authored-by: Cursor trailers in git history, commit often from Cursor Agent, export transcripts into the repo, and screen-record Cursor in the Devpost video. A public shared-transcript link needs a Teams seat ($40). The brief wants real space data, but per the ceremony it is optional.

**What judges rewarded at other 2025-2026 events:** Grok Voice (low-latency speech) or Grok Imagine as the primary interface or output, not decoration. Documented heavy Cursor use: show Cursor agent sessions, rules files and commit history in the Devpost and pitch. Grok Bot for planning is a bonus. A space theme is optional in practice (both 2026 student winners were civic or campus tools), but cheap space framing could still tip a tie. Grok voice calls that hand off to iMessage (Gotchu) stack naturally with Photon.

Examples: DivHacks 2026 winner: NOVA, a K-5 STEM program finder by ZIP code with a Grok-powered voice chatbot in about 20 languages. No space theme at all. HackCMU 2026 (900 hackers) winner: Gotchu, a campus task marketplace used over iMessage or a phone call. It used the Grok Responses API with tool calling, Grok Voice for calls that continue in iMessage, an ethics agent, a price-negotiating agent, and optional Grok image/video previews. SpaceXAI Grokathon (Aug 2026, SF) winners: Nova (Grok reverse-engineers binaries into C), ThinkVoice (Grok Voice + brain sensing). Coverage said judges wanted Grok as 'infrastructure, not a chatbot'. DivHacks 1st place (Julia's Time Machine) listed Cursor plus Grokbot agents for team collaboration.
