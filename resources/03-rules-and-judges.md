# Rules and judges

Source: Devpost (page-fetch summaries; curl gets 403). Tracks: [tracks/](tracks/README.md). Submission and judging format: [01-general-info-doc.md](01-general-info-doc.md).

## Rules
- 18+, college students only, no professional organizations.
- Team 1-4, all students, all present at the event.
- Need a public GitHub or Google Drive link.
- All work during the hackathon. Prior *ideas* OK; reusing prior *code* not. Libraries, frameworks, open source allowed; pre-written code made only to use in the event violates the spirit.
- Stop hacking at the deadline. Minor debugging OK; no large changes or new features.
- Code of Conduct applies; organizers can disqualify.
- 2025 rule that may still hold: can enter multiple side tracks.

## Judges
Devpost lists 17 (Meta x3, Google, Amazon, Palo Alto Networks, Lyft, Databricks, DianaHR, others). Names not captured. Main-track criteria: technical skill, design, creativity, impact, theme adherence ([tracks/bigred-main.md](tracks/bigred-main.md)).
