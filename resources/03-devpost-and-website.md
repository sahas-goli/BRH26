Application deadline was Sep 9, 2026 11:59 PM ET; after that, waitlist applications only. It also holds organizer/admin tooling (not for hackers).

## Eligibility and rules
- 18+, college students only, no professional organizations. Participants pick side tracks on Devpost.
- Team 1-4, all students, all present at the event.
- Need a public GitHub or Google Drive link.
- All work during the hackathon. Prior *ideas* OK; reusing prior *code* not. Libraries/frameworks/open source allowed; pre-opening code only to use it in the event violates the spirit.
- Stop hacking at deadline. Minor debugging OK; no large changes or new features.
- Code of Conduct applies; organizers can disqualify.
- 2025 rule that may still hold: can enter multiple side tracks.
