Six Hops is a typed Next.js product. You can run it from a Photon text or from `/post`, through a personal `/h` link, to This is me, to Accept and pay. `FANOUT` in `web/lib/types.ts` is 3, and `H` is 8. `splitCents` in `web/lib/split.ts` pays each passer `floor(B/16)`, and the match gets the rest, so the shares sum to `B`. A finder who inserts fake hops collects the same total, which the attack slider on `/live` shows next to the MIT gain. `npm --prefix web run check` covers the split tests and the post, forward, claim, and confirm path. `npm --prefix web run smoke:mock` runs that path on PGlite.
