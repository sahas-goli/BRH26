Free text for a search goes through `compileHintCard` in `web/lib/hintcard.ts`. It calls Gemini, default model `gemini-3.8-flash`, and asks for JSON matching a fixed schema. The public hint is only city, organization type, field, skill, language, and experience. The instruction tells the model to drop names, emails, phones, and street addresses, and to keep places at city level. `sanitizeCompiledHint` runs on the server after that: unknown keys are dropped, strings are clipped to 80 characters, and organization type has to be one of the seven allowed values. The unit test feeds a name and a street address and checks that neither field survives. `POST /api/bounties` wires that compiler to the text body before it stores the hint.
