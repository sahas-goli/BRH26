# 2-minute pitch (from PLAN §12)

Use with `/live` on the projector (local: `npm --prefix web run seed:demo && npm --prefix web run dev`). Fallbacks: backup video (AL-03); Photon down → phone `/h` link; slow devnet → last good Explorer sig.

## Script

**0:00–0:20 — Hook**  
The person you need is usually 2 to 4 hops away in someone’s private contacts. Jon Kleinberg proved strangers can find each other with local knowledge alone. We made the chain pay, correctly.

**0:20–0:50 — `/live`**  
Overnight game cascades and depths next to the 1M-event replay. Point where **b** fell below 2 and the controller widened the hint; table gauge tracks the same `b`.

**0:50–1:15 — Judge hop**  
Registered judge gets a bounty (iMessage wanted-card preview, or `/h` link). They reply with a name → new edge on the graph.

**1:15–1:40 — Claim + pay**  
Teammate as target: badge code (or intro-only), opt in. ~2 s one Solana tx pays every hop → Explorer. Nessie panel only if live escrow works (else mock).

**1:40–2:00 — Attack slider**  
Finder adds 1–4 fake recruiters: MIT +50/75/88/94%; ours +0%; poster total unchanged.

## Q&A crib

| Challenge | Answer |
|---|---|
| Pyramid? | Nobody pays to join; one poster; fixed total; depth ≤ 8. |
